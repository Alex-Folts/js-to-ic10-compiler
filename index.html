Introduction

This page describes the JS → IC10 compiler features available.

Currently implemented JS features

  • var, let, const supports only numbers; true and false get converted to 1 and 0 respectively; string values attempts to parse to a number.
  • Comparison operators: <, >, ==, !=, ===, !==, >=, <=.
  • Arithmetic operators: +, -, *, /, %.
  • Logical operators: &&, ||.
  • Compound operators: +=, -=, *=, /=.
  • Unary operators: -, !.
  • Conditional (ternary) operator: condition ? exprIfTrue : exprIfFalse.
  • Implemented flow control: while, for loops, switch-case statement, if-else statement, break, continue .
  • User-defined functions, nested calls and limited recursion.

IC10 virtual library

  • IC10.d0..IC10.d5, IC10.db device pins, e.g. IC10.d1.On = 1.
  • IC10.sleep(seconds) — emits IC10 sleep instruction.
  • IC10.yield() — emits IC10 yield instruction.
  • IC10.hcf() — emits IC10 hcf instruction.
  • IC10.HASH(str) — insert IC10 HASH("str").
  • Extendable: register new handlers in callHandlers.js.

Math.* → IC10

Common Math.* functions are translated to IC10 ops. Not all functions are exact; some are emulated (e.g. cbrt via Newton iterations).

acos, asin, atan functions behave differently: in IC10 for parameter values <1> it returns 0, while in JS it return NaN.

Limits, lines, stack

IC10 programs are limited to 128 lines by the game. The UI shows a line counter. In compact mode the compiler uses numeric jump targets to reduce line overhead.

Stack has total of 512 values, compiler uses stack for defining global variables, and stashing registers when do user-defined function calls.

User-defined functions limited to maximum of 4 arguments.

No scopes, scope blocks {...} parses properly, but all variables/consts/functions implemented as a globals.
